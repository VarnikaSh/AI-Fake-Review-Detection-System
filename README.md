# 🔍Review Intelligence Dashboard

## Overview
An AI-powered Fake Review Detection System built using NLP, Mchine Learning, and Streamlit.

## Features
- Detects Fake and Genuine Reviews
- Sentiment Analysis
- Confidence Score Visualization
- Review Statistics Dashboard
- Suspicious Phrase Detection
- Word Cloud Visualization
- Intractive Streamlit Interface

## Tech Stack
- Python
- Scikit-Learn
- Pandas
- Streamlit
- TextBlob
- WordCloud
- Matplotlib

## Machine Learning Techniques
- TF-IDF Vectorization
- Logistic Regression
- Natural Language Processing (NLP)
- Text Classifiaction
